# Third Eye Search: Website Prototype

Front-end prototype built from the *Third Eye Search Website Content & Implementation Guide* (November 2026).

Pages: Home, About Us, Recruitment & Jobs, Hire Talent & Workforce, Talent Development, Remote Work Essentials, Contact & Support.

All jobs, products and prices are **sample data**. Forms show confirmation messages only and save nothing.

## Structure
- `index.html`: page shell
- `css/styles.css`: styles (light and dark mode)
- `js/app.js`: page content, sample data and routing (`#home`, `#about`, `#jobs`, `#hire`, `#learn`, `#store`, `#contact`)

## Publish with GitHub Pages
1. Upload all files and folders to the root of a **public** repo.
2. Settings, then Pages, then Deploy from a branch, then `main` and `/ (root)`.
3. Open the link shown at the top of the Pages settings.
